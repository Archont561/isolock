## Hello World

Welcome to the **Isolock** documentation site built with [Fumadocs](https://fumadocs.dev).

Isolock is a deterministic, content-addressable dependency airlock system designed for reproducible builds, compliance auditing, and secure software supply chains across multi-language repositories.

## Core Features

- **Multi-Ecosystem Interception**: Transparent proxy routing for Conda, PyPI, npm, and Cargo.
- **Fail-Closed Package Paths**: Missing proxy artifacts fail closed; locked materializers do not resolve upstream. These are not OS/network sandboxes.
- **Content-Addressable Storage (CAS)**: SHA-256 sharded storage engine caching verified upstream artifacts.
- **Lockfile Drift Guard**: Detects tampered, missing, or mismatched package digests before deployment.
